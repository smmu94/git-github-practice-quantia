## Flujo de trabajo 
1. Crear una rama desde `main` actualizado: `git switch main`, `git pull`, `git status` (comprobar que el árbol está limpio, sin cambios sin commitear) y `git switch -c feature/nombre-de-la-rama`.
2. Hacer commits pequeños con Conventional Commits (`feat:`, `fix:`, `docs:`) y subir la rama con `git push -u origin feature/nombre-de-la-rama`.
3. Abrir un Pull Request hacia `main` en GitHub, pedir review a un compañero y hacer merge cuando esté aprobado.
